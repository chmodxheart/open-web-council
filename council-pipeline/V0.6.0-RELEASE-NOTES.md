# Council of LLMs v0.6.0 Release Notes

**Release Date**: 2025-12-06

## New Features

### Synthesis Mode Toggle

New `SYNTHESIS_MODE` Valve allows you to control how the Council produces its final output:

| Mode | Description |
|------|-------------|
| `full` (default) | Lead model synthesizes insights from all responses |
| `highest_rated` | Returns only the highest-scoring response (no synthesis) |
| `none` | Shows responses and scores only, displays the winner |

This feature enables faster queries when synthesis isn't needed, or when you want to see the "raw" winning response without additional processing.

### Token Usage Tracking

New detailed token tracking shows exactly how many tokens each model used in each phase:

- **Initial Query**: Input and output tokens for the initial response
- **Evaluation**: Tokens used when evaluating other models' responses
- **Synthesis**: Tokens used for the final synthesis (if enabled)

Controlled by the `SHOW_TOKEN_USAGE` Valve (default: true).

### Cost Estimation

New cost tracking feature lets you estimate API costs per query:

1. Configure costs per model with `MODEL_COSTS_JSON`:
   ```json
   {
     "gpt-4": {"input": 0.03, "output": 0.06},
     "claude-3-opus": {"input": 0.015, "output": 0.075}
   }
   ```
   (Costs are per 1,000 tokens)

2. Enable `SHOW_COST_ESTIMATE` to see cost breakdown by model and phase

## New Valves

| Valve | Default | Description |
|-------|---------|-------------|
| `SYNTHESIS_MODE` | `"full"` | `full`, `highest_rated`, or `none` |
| `SHOW_TOKEN_USAGE` | `true` | Show detailed token breakdown per model |
| `MODEL_COSTS_JSON` | `"{}"` | Per-model cost configuration (JSON) |
| `SHOW_COST_ESTIMATE` | `false` | Show estimated costs (requires MODEL_COSTS_JSON) |

## Configuration Examples

### Quick Evaluation Mode (No Synthesis)
```
SYNTHESIS_MODE = "none"
```
Get responses and scores without waiting for synthesis. Great for quick comparisons.

### Winner-Takes-All Mode
```
SYNTHESIS_MODE = "highest_rated"
```
Skip synthesis and return the top-scoring response directly.

### Cost-Aware Mode
```
SYNTHESIS_MODE = "full"
SHOW_TOKEN_USAGE = true
SHOW_COST_ESTIMATE = true
MODEL_COSTS_JSON = {"gpt-4": {"input": 0.03, "output": 0.06}, ...}
```
Full synthesis with detailed cost tracking.

## Upgrade Notes

- This is a drop-in replacement for v0.5.0
- All existing Valves remain unchanged
- Default behavior is identical to v0.5.0 (`SYNTHESIS_MODE = "full"`)
- Token tracking is now more granular (input/output separated)
